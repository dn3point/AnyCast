找不到电视？
  • 确认手机、电视、运行网关的设备在同一个 Wi-Fi。
  • 电视需开启 DLNA / “投屏接收” / “无线显示”或乐播投屏等功能（多数智能电视默认开启）。
  • 老电视或没有 DLNA 的电视：用电视自带浏览器打开 ，它就会出现在上面列表里。
